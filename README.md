# ENPM661_Project2
repository for ENPM661 Project 2 code
- This code uses the Dijkstra algorithm to find the optimal path on an obstacle layout from a starting point to a goal point chosen by the user.
- Once the path is found, an animation showing the node exploration part of the search and the optimal path is displayed.
- To run the code, download all the code files into one folder, then run the main file called "dijkstra_main.py"
